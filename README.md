# Expense Tracker

A responsive Expense Tracker web application built using HTML, CSS, JavaScript, and Bootstrap.

## Features

- Add income and expense transactions
- Enter amount, category, date, and description
- Edit and delete transactions
- View total income, total expenses, and current balance
- Filter transactions by income or expense
- Filter transactions by category
- Search transactions
- Save transaction data using browser Local Storage
- Responsive design for desktop and mobile screens
- Monthly expense summary
- Category-wise expense chart
- Form validation and helpful error messages

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Bootstrap Icons
- Local Storage

## How to Download

### Download ZIP

1. Open the GitHub repository.
2. Click the **Code** button.
3. Select **Download ZIP**.
4. Extract the downloaded ZIP file.
5. Open the extracted project folder in Visual Studio Code.

### Clone the Repository

Alternatively, clone the repository using Git:

```bash
git clone https://github.com/Elone-debug/expense-tracker-elbin-sojan.git
```

## How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Install the **Live Server** extension in VS Code.
4. Open `expense.html`.
5. Right-click on `expense.html`.
6. Select **Open with Live Server**.
7. The application will open in your default web browser.

No backend or database setup is required.
